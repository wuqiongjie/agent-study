## 本次的「原来如此」

- Agent demo 的本质是 `while` 循环 + `messages` 数组 + 工具函数；框架只是给它加状态、分支、并发与中断。
- 模型只输出「调用意图」，**执行永远在本地**——工具是模型的手。
- Agent 不干活时，优先怀疑工具描述（tool description）写得烂，而不是模型不行。
- 前端在 Agent 产品里的价值不在管道，而在：流式与可中断、工具调用可视化、成本与延迟控制。
